# Competitor SEO and content-gap analysis

## Workflow
1. Use the user's market, service and sample queries to identify three to six **direct competitors** and relevant directories. Exclude irrelevant job listings from direct-competitor comparisons.
2. Read the actual public pages using the existing Firecrawl skill rather than relying on snippets alone.
3. Record for every page: URL, title, clear buyer intent, geo specificity, related topic links, FAQs, first-hand examples, expert authorship, testimonials, external credentials, and conversion path.
4. Separate observable facts from causal hypotheses. Ranking is multifactorial; an observed keyword-rich title does not prove it caused a position.
5. Audit whether the user's current site already addresses each topic. Avoid generating duplicate content when a smaller improvement to an existing page is more useful.
6. Produce a content-gap matrix: question/intent, target page or new article, unique original evidence needed, commercial CTA, effort, priority, and verification metric.
7. Recommend real third-party recognition, editorial mentions, credible association speaking opportunities, and published case studies. Never recommend paid link schemes, fabricated endorsements or self-serving fake rankings.

## Deliverable
- Direct-competitor comparison table with source URLs.
- Top three immediate technical/content fixes and a four-week publishing sequence.
- Distinct labels for confirmed observations, interpretation, and items requiring access (Search Console, backlink provider).
