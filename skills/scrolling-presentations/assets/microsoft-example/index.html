  • Reuse your existing automation

  • Add desktop automation when needed

“Route approval.

Choose by ownership, existing flows, desktop needs, and licensing.

Why the overlap matters

Agent flows are closely related to Power Automate cloud flows. The decision is often where you author and manage the workflow and which capacity or licensing model pays for it. Power Automate includes desktop automation; agent flows focus on the Copilot Studio workflow experience.

Both can run without a chat. An agent flow does not mean the AI invents every step. Power Automate can also participate in agent solutions. Reuse an appropriate existing flow before duplicating it.

Microsoft supports converting a solution-aware Power Automate cloud flow to an agent flow. This changes billing to Copilot Studio capacity and is currently one-way. Compare your actual licensing and usage before converting. Microsoft’s conversion guidance ↗

How these connections work

An agent flow creates the Dataverse request. Power Automate reacts to a record change. Power Pages adds the supplier’s quote. Power Apps gives staff a view of the same request.

Foundry is an optional custom integration. Copilot Studio’s direct Foundry-agent connection is in preview; support differs by agent experience. All connections need permissions and configuration. [10]
